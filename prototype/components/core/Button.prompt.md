Rectangular uppercase-Montserrat button; use for all CTAs.
```jsx
<Button variant="primary" size="md">Begin Your Journey</Button>
<Button variant="secondary">View Itinerary</Button>
<Button variant="ghost">Learn more</Button>
```
Variants: primary (brass fill), secondary (brass hairline outline), ghost (underlined text link). Sizes sm/md/lg. Never pill-shaped, never bold weight.
