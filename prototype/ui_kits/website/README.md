# Fairway Atelier — Website UI kit
Marketing-site screens for the Brittany, France golf journey, aligned to the Round 2 technical spec (`uploads/Website_technicals.docx`). Enquiry-first: no online deposits. Screens: Home, Experience, Journey (dual-tier: Standard/EMERIA, Signature/Barrière), Availability (weeks with Booking/Limited/Sold/Waitlist status), Enquire (≤8 fields → consultation call). Footer carries the Atout France + named-asset disclosures required on every page. Primitives from `components/`; assets from `assets/`. Not covered here (content/legal pages): Dining & Golf, Private, FAQ, Journal, and the French legal pages (mentions légales, privacy, terms/CGV, cookies) — build from the same primitives when needed.
